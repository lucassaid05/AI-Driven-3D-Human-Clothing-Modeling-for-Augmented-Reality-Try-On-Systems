AR Virtual Try-On Prototype

A real-time webcam AR try-on built for this dissertation. A 3D garment is generated from a pair of front/back images and fitted to a pose-tracked body, then composited over the live camera feed.

Launch the prototype

3D · AR

The prototype is a bundled Vite app served from dist/apps/ar-tryon/. It requires camera access, so it must be opened over localhost or HTTPS. Make sure you've run npm run build at least once, or start npm run dev and use the dev link below.

Launch Prototype → Open in Vite Dev ↗

SAM3 generated model

SAM3 · GLB

This garment is bundled as shirt_canonical.glb (segmentation / mesh from SAM3). Use either launch button below: the app loads the model from the link, then tap Start Camera in the controls panel to see it on your body.

Launch with SAM3 model → Open in Vite Dev ↗

How it works

1. Capture

Front & back garment photos are uploaded and preprocessed into a 3D-ready pair.

2. Generate

A pose-ready GLB is produced server-side, then delivered to the browser.

3. Try On

The garment is rigged to a pose-tracked body and rendered over the webcam feed.

Mobile tip: open the dev server URL on a phone on the same Wi-Fi (e.g. https://<your-LAN-IP>:5173/apps/ar-tryon/) and allow the self-signed certificate to enable camera access on iOS Safari and Android Chrome.
